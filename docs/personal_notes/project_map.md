# RP2 Project Map

Last updated: 2026-04-26

## Active Working Folders

- `data/final_stimuli/`: current final or working-final stimulus files.
- `data/processed_corpus/`: generated corpus frequency tables.
- `data/candidate_pools/`: candidate pools and shortlists used to select stimuli.
- `scripts/`: reproducible processing, selection, and R setup scripts.
- `docs/diagnostics/`: diagnostics, review notes, manifests, and setup status.
- `docs/reference_notes/`: proposal, rule book, examples, literature notes, and personal notes.

## Archive Folders

- `archive/stimulus_selection_history/`: previous real-word versions and manual review files.
- `archive/legacy_sample_corpus_2026-04-26/`: old `data_sample` folder kept for reference only.
- `archive/cleanup_2026-04-26/`: prior cleanup checkpoints and superseded notes.
- `archive/raw_sources/`: original compressed corpus source.
- `archive/Train_Full/`: extracted full raw corpus text files.
