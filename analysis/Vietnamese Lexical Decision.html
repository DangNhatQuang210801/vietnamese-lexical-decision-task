RP2 Analysis: Vietnamese Lexical Decision Task

Dang Nhat Quang

This document is an analysis draft for the RP2 Vietnamese lexical decision task. The aim is to check the cleaned data, describe the main patterns, and fit the first mixed-effects models for reaction time. Python was used before this step only to create cleaned data files and quality-control outputs. The raw PsychoPy files are not edited here.

To render from the project root, run:

rmarkdown::render(
  "analysis/RP2_final_analysis_v2.Rmd",
  output_file = "RP2_final_analysis_v2.html",
  output_dir = "analysis/outputs/r_analysis"
)

Why mixed-effects modeling is needed

This experiment is a repeated-measures lexical decision task. Each participant responded to many items, and each item was seen by many participants. Therefore, observations are not fully independent. A simple linear model would ignore participant-level and item-level variability. Mixed-effects models are appropriate because they allow participants and items to be modeled as random effects (Baayen, Davidson, & Bates, 2008; Bates et al., 2015).

Why log RT is used

Reaction-time data are usually right-skewed. For this reason, RT analyses often use transformed RTs or otherwise check distributional assumptions. In this project, log_rt is used as the dependent variable for the main RT models. This follows common practice in RT analysis, while the diagnostic plots below are still checked carefully (Baayen & Milin, 2010).

Random effects note

Participants and items are included as random intercepts because both can introduce variability. Some participants are generally faster or slower, and some items are generally easier or harder. Including both random effects follows the logic of crossed random effects for subjects and items (Baayen et al., 2008).

Descriptively, high-frequency words appear faster than low-frequency words if the high-frequency mean RT is lower. In the current data, the high-frequency mean RT is 0.51 seconds and the low-frequency mean RT is 0.668 seconds.

Descriptively, RT appears to increase with syllable length if the mean RTs rise from one to four syllables. This descriptive pattern should be checked together with the mixed-effects model.

The interaction model is useful because it tests whether the frequency effect changes across syllable lengths. The model comparison table should be used to decide whether this additional complexity is justified. The interaction comparison p-value is 0.0449.

Accuracy is also part of the quality check. The overall accuracy is 0.902, which suggests that participants generally performed the lexical decision task seriously. This is still a preliminary analysis draft. Final report wording should be written only after reviewing the model output, residual plots, singularity status, and VIF results.
